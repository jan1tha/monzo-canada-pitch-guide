# Monzo Canada — A2 pitch guide

Group study material for MS70087E Global Marketing and Digital Business.

The page is served from GitHub Pages and its contents are **encrypted at rest** with
AES-256-GCM. The key is derived from the group password with PBKDF2-SHA256 at 600,000
iterations. Decryption happens in the browser; the password is never sent anywhere and is
not stored in this repository.

`index.html` is the password gate. `payload.json` is the encrypted page.
